# ВинКрым — учебная clean-room копия интерфейса vinealytics.com

Учебный проект из серии «разбор сайтов для самообразования»: воспроизводит
**поведение и структуру** сайта www.vinealytics.com (платформа точного
виноградарства), но с нуля и на своих данных:

- регион — **Крым**: точки расчёта — реальные винодельни (Винодельня Акчурина · Терновка, UPPA Winery · Родное, Золотая Балка · Балаклава);
- язык интерфейса — **русский**, единицы — метрические (°C, м/с, мм);
- бренд и контент оригинала **не копируются**: своё имя, свои тексты и данные.

## Стек

React 19 + Vite + React Router (hash-роутинг, как в оригинале) + Recharts.
Без Tailwind/shadcn: дизайн-токены оригинала (тёмная тема, зелёный акцент
`hsl(147 39% 39%)`) перенесены в `src/styles.css` как CSS-переменные.

## Данные

Вся «серверная» часть — два GET-запроса к открытому [Open-Meteo API](https://open-meteo.com/)
(живые, без ключа), ровно как у оригинала:

| Запрос | Что даёт |
|---|---|
| `api.open-meteo.com/v1/forecast` | текущая погода, 24 ч почасово, 7 дней, ЭТП₀ |
| `archive-api.open-meteo.com/v1/archive` | дневные температуры за 10 лет — из них GDD текущего сезона и среднее 10 лет |

Агрономия (`src/lib/gdd.js`):

- **GDD** (градусо-дни роста): `max(0, (Tмакс + Tмин)/2 − 10°C)`, накопление с 1 апреля;
- **среднее 10 лет**: нарастающие кривые прошлых сезонов, усреднённые по дню года;
- **прогноз даты сбора**: экстраполяция темпа последних 30 дней до цели 1650 °C·дн,
  три сценария ±20% (учебная модель, не агрономическая рекомендация).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
```

Маршруты: `/` — лендинг · `/login?demo=true` — вход в демо (любая почта/пароль) ·
`/app` — дашборд · `/app/weather` · `/app/blocks` · `/app/analytics` · `/app/alerts`.

## Что разбирать для обучения

1. `src/lib/openMeteo.js` — как сайт получает погоду; сравни с запросами
   оригинала в DevTools → Network (там фаренгейты, здесь °C).
2. `src/lib/gdd.js` — прикладная математика на клиенте.
3. `src/hooks/useWeather.js` — один архивный запрос закрывает и сезон,
   и климатологию (оригинал делает несколько).
4. `src/pages/*` — разница между маркетинговым лендингом и приложением-дашбордом.
5. `src/components/GddChart.jsx` — наложение двух кривых в Recharts.

## Публикация на GitHub Pages

1. `main` — только исходники; правка `vite.config.js` (`base: './'`) обязательна и живёт в `main`.
2. Публикация: `npm run build` → `git add -f dist && git commit` → `git subtree split --prefix dist -b gh-pages` → `git push -f origin gh-pages` → `git reset --hard HEAD~1` (сбрасывается только коммит с dist).
3. CDN GitHub Pages кэширует `index.html` до ~10 минут — новый бандл по прямому URL доступен раньше.

## Отличия от оригинала

- GSAP-анимации заменены CSS (`AnimatedTitle` на лендинге);
- «бэкенд» оригинала хранит данные в localStorage (`vinealytics_db`) — здесь
  статический справочник `src/data/estate.js`;
- страницы Pricing/About/Reports/Billing не воспроизводились (не несут
  учебной нагрузки).
